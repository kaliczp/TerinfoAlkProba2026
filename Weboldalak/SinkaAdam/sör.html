Szeretnéd saját mappában, Git Bash segítségével kezelni és verziókövetni ezt az oldalt? Töltsd le a fenti gombbal az index.html fájlt, majd futtasd az alábbi parancsokat a Git Bash terminálban:

# 1. Projekt mappa & Git indítása 
mkdir sor-kalkulator
cd sor-kalkulator
touch index.html
git init
# 2. Fájl hozzáadása & Commit 
git status
git add index.html
git commit -m " feat: sor terfogat szamolo hozzaadva"
start index.html
